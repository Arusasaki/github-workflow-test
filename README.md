# GitHub Workflow Test

This repository is for testing the GitHub development workflow with Antigravity AI.

## Workflow

1. **Issue Creation** - Track features and bugs
2. **Branch Creation** - `feature/xxx` for new features
3. **Development** - Code changes with Antigravity
4. **Pull Request** - Submit for review
5. **Code Review** - Antigravity reviews the PR
6. **Merge** - Merge to main after approval

## Tech Stack

- Next.js (planned for factoring comparison site)
- TypeScript
- Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```
